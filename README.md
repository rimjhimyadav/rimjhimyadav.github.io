# My Portfolio

My personal portfolio website made with React and Vite.

🔗 **Live:** https://rimjhimyadav.github.io

## Sections

- Home
- About me and education
- Skills
- Projects
- Contact

## Built with

- React
- Vite
- CSS
- ESLint
- GitHub Pages (deployed with GitHub Actions)

## Run locally

```bash
npm install
npm run dev
```

## Add a new project

Add it to the list in `src/projects.js` and put a screenshot in `public/images`.
